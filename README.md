# Expense Tracker

## About the Project
Expense Tracker is a web-based application developed using Python and Flask. It helps users record and manage their daily expenses easily.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite

## Features
- Add expenses
- View expenses
- Manage expense records
- Simple and user-friendly interface
- Store expense data in a database

## Project Structure
- `app.py` – Main Flask application
- `templates/` – HTML files
- `static/` – CSS and other static files
- `expenses.db` – SQLite database
- `init_db.py` – Database initialization

## Purpose
This project was developed as a mini project to learn Python, Flask, web development, and database management.
